# Limbes — maquette cliquable

Une page où l’on peut tout dire. Maquette de l’entrée, du guidage et de la fin, à vivre sur un téléphone.

**→ https://chtabay.github.io/Absolution/limbes/**

## Ce qui est vrai dans la maquette

- L’écran unique : la page, le texte fantôme qui tourne, les amorces, les deux mots en bas (« autrement », « quitter »).
- Le nuage des mots, disposé selon le circumplexe (agité / éteint × douloureux / supportable).
- Les cartes qu’on tire, dans n’importe quel ordre, avec leurs précisions.
- La ligne d’aide en trois niveaux : rien, une ligne douce refermable, une ligne qui reste avec un bouton d’appel. Détection locale par mots-clés, jamais nommée.
- Le tiroir « autrement » : choisir un mot, me situer, dire en trois lignes, parler à quelqu’un.
- Les trois gestes : garder ici (sur le téléphone), brûler, transmettre.
- Le brouillon reste sur le téléphone ; « quitter » mène à une page neutre.

## Ce qui est faux dans la maquette

- Les chiffres de l’écran « où tu es parmi les autres » sont inventés.
- « Transmettre » n’envoie rien nulle part.
- Le stockage local n’est pas chiffré, et il n’y a pas de verrou. La vraie version aura les deux.

## Modifier

Amorces, mots, cartes, sujets, mots-clés d’alerte et numéros : en tête de `limbes.js`.
